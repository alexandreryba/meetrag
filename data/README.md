# Demo data: Voltaria Energy

**Voltaria Energy is fictional.** Every document, name, price and procedure in this folder was
written for this project; any resemblance to a real company is coincidental.

| Folder | Source | Content |
|---|---|---|
| `corpus/policies` | `policies` | Remote work, leave, travel and expenses, information security, gifts and ethics |
| `corpus/products` | `products` | Offer catalogue, Fixe 3 ans, Verte, Drive (EV), solar and heat pumps, smart meter FAQ |
| `corpus/support` | `support` | Billing disputes, outages, retention playbook, moving, SLA and escalation matrix |

The analytics database (`offers`, `customers`, `monthly_consumption`, `support_tickets`) is
generated by `polyrag ingest` with a fixed seed (`src/polyrag/demo/voltaria_db.py`), so every
run produces the same rows. Offer prices in the database match the product documents; a test
checks it.

To use your own documents, create the same three sub-folders (Markdown, text, HTML or PDF) and
set `POLYRAG_CORPUS_DIR`.
